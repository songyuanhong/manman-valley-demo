# 慢慢谷物语 · 试玩版

一款用身体玩的休闲体感游戏：站在屏幕前走、蹲、举手，小满和噗噗就在慢慢谷里帮大家送面包、让湖水倒流。

**在线试玩**：https://songyuanhong.github.io/manman-valley-demo/

试玩版包含：动作教学、第一站「送面包的早晨」、第二站「倒流湖」。其余地点在完整版开放。

- 用身体玩：电脑或电视接摄像头，点左下角「📷 体感」→「开启摄像头」，站到屏幕前 2–3 米，全身入镜。动作识别在浏览器本地完成，画面不录制、不上传。
- 用键盘玩：方向键、空格、回车；按住 ↑ 等于双臂举高。
- 建议使用电脑版 Chrome 或 Edge。

本仓库只包含试玩版的构建产物，不含源代码。

第三方组件：MediaPipe Tasks Vision 与 Pose Landmarker 模型（Apache 2.0，运行时从官方 CDN 载入，许可见 `motion/`）；字体 LXGW WenKai、ZCOOL XiaoWei（SIL OFL 1.1，许可见 `fonts/`）。
